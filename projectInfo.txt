# Flip-Cart E-Commerce Website

## Project Overview
Flip-Cart is a secure and user-friendly e-commerce platform designed to provide a seamless shopping experience. It enables users to browse, select, and purchase products effortlessly, while ensuring data integrity and security throughout the buying process.

## Key Features
- **User Registration & Authentication:** Email verification on signup, secure login, and password reset functionality.
- **Personalized Cart Management:** Users can add/update multiple products with smart grouping by size and color, and real-time stock availability checks.
- **Order & Payment Processing:** Smooth checkout flow with payment gateway integration ensuring secure and complete payment processing.
- **User Reviews:** Supports posting and retrieving product reviews via RESTful APIs.
- **API Integration:** Integrates third-party APIs to fetch and update product data dynamically.
- **Admin API Generator:** Custom API generator for any model in the system, simplifying backend management.
- **Cart Persistence:** User cart data is preserved across sessions and logins for better user experience.
- **Security:** Implements secure coding best practices, protecting user data and transactions.

## Technologies Used
- Python & Django Framework
- Django REST Framework (DRF)
- PostgreSQL / MySQL
- JavaScript, HTML, CSS (Frontend)
- Third-party Payment Gateway APIs
- Git for Version Control

## How to Run
1. Clone the repository.
2. Setup virtual environment and install dependencies (`pip install -r requirements.txt`).
3. Configure database settings in `settings.py`.
4. Run migrations and create superuser.
5. Start the development server (`python manage.py runserver`).
6. Access the app via `http://localhost:8000`.
